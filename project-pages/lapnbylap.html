LapByLap - F1 Fantasy Web Application
A full-stack web application that provides data-driven F1 Fantasy team recommendations through Monte Carlo simulations, real-time race data analysis, and optimisation algorithms. The platform combines statistical modelling with a user interface to help users make informed fantasy team decisions.
Live application available at lapbylap.karimabbas.com
Project Overview
LapByLap is an ongoing side project that evolved from a proof-of-concept Python script into a web application. The platform uses Monte Carlo simulation techniques to model Formula 1 race outcomes and optimise fantasy team selections based on statistical analysis of historical race data. The application provides insights through visualisations and race predictions.

The system processes official F1 timing data to extract driver performance metrics, track characteristics, and race dynamics. These parameters feed into a simulation engine that runs thousands of race scenarios, generating probability distributions for finishing positions and fantasy point outcomes. The optimisation layer then selects team compositions within budget constraints, balancing expected value with risk-adjusted returns.
Technologies & Architecture:
  • Frontend: React with Vite for UI development. Three.js integration for visualisations and race simulations.
  • Backend: FastAPI framework providing RESTful API endpoints for simulation execution, data retrieval, and team optimisation. PostgreSQL database for storing race data and simulation results.
  • Simulation Engine: Custom Monte Carlo implementation running 5,000+ iterations per race, modelling lap-by-lap progression with stochastic position changes, tyre degradation, fuel effects, and race events.
  • Optimisation: Linear programming using PuLP library to solve multi-objective team selection problems within F1 Fantasy budget constraints.
  • Data Processing: FastF1 library for extracting official F1 timing data. NumPy and Pandas for statistical analysis and data aggregation.
  • Deployment: Docker containerisation with Nginx reverse proxy and SSL certificate management.
Core Features

The application provides several features for the F1 Fantasy experience. The Race Week module generates team recommendations for upcoming races, incorporating current driver prices, recent form, and track-specific characteristics. The Analytics section offers visualisations including position progression charts, value analysis quadrants, and animated lap-by-lap race simulations that show how driver positions evolve throughout a race.

The Backtesting functionality allows users to evaluate historical performance by running simulations on past races and comparing predicted outcomes against actual results. The My Team section provides team management, allowing users to track their selections and compare them against recommendations.
Monte Carlo Simulation Methodology

The simulation engine models race outcomes through probabilistic sampling of driver performance distributions. Each simulation runs lap-by-lap, with driver positions evolving based on pace advantages, volatility factors, and stochastic events. The model incorporates track-specific parameters such as overtaking difficulty, safety car probability, and weather conditions. Driver performance is characterised by statistical distributions derived from historical qualifying and race lap times, accounting for variability in performance consistency.

The simulation accounts for multiple race dynamics including tyre degradation effects that progressively slow drivers over race distance, fuel load impacts that improve lap times as fuel burns off, and traffic penalties that affect drivers based on their position. Safety car periods and weather events are modelled probabilistically based on historical track data. Each simulation generates a complete race outcome, producing distributions for finishing positions, fantasy points, and team performance metrics.
Team Optimization Algorithm

The optimisation layer employs multi-objective optimisation to select team compositions. The algorithm balances expected value maximisation with risk-adjusted portfolio theory, considering both mean performance and variance in outcomes. For large league formats, the optimiser incorporates upside potential analysis, selecting teams with higher variance that can outperform in favourable scenarios.

The optimisation problem is formulated as a linear programming model with constraints including total budget limits, maximum driver and constructor selections, and team representation limits. The solver evaluates thousands of potential team combinations, scoring each based on expected points, risk metrics, and value efficiency. The algorithm also identifies multiplier selections (2x and 3x drivers) that maximise expected returns.
Data Pipeline & Processing

The application maintains a data pipeline that processes official F1 timing data from completed races. The FastF1 library extracts telemetry including lap times, sector times, tyre compounds, and race events. This raw data undergoes aggregation and statistical analysis to compute driver performance parameters such as mean qualifying pace, race pace distributions, tyre degradation rates, and DNF probabilities.

The data processing layer handles missing data, accounts for track evolution effects in qualifying, and normalises performance metrics across different track types. Historical data is weighted by recency to capture current form, with more recent races having greater influence on performance predictions. The system maintains a cache of processed race data to optimise simulation execution times while ensuring data freshness.
Visualization & User Experience

The frontend provides visualisations that make statistical outputs accessible to users. Position progression charts show how driver positions evolve throughout a race, with animated GIFs illustrating lap-by-lap movement. Value analysis quadrants plot drivers based on expected points versus cost, helping users identify high-value selections. The application uses Three.js for visualisations.

The user interface is designed for clarity and ease of use, with responsive layouts that work across desktop and mobile devices. Loading states and progress indicators provide feedback during simulation execution. The design incorporates F1 team colour schemes and branding elements aligned with the sport's visual identity.
Development & Future Enhancements

This project represents an ongoing effort to develop and maintain the application while continuously improving the underlying models and user experience. The system is maintained and updated throughout the F1 season, with new features and refinements added based on user feedback and performance analysis.

Planned enhancements include real-time data integration for live race updates, machine learning integration to improve prediction accuracy, advanced strategy modelling that accounts for pit stop timing and tyre compound selection, and social features that enable users to share team selections and compete in leagues. The application serves as a platform for continuous learning and skill development, particularly in full-stack development, statistical modelling, and data science applications.
