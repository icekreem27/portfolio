🏎️ F1 Fantasy Predictor - Technical Documentation
A comprehensive technical deep-dive into the statistical methodologies, Monte Carlo simulations, and machine learning techniques powering AI-driven F1 Fantasy team recommendations.
System Architecture Overview
The F1 Fantasy Predictor employs a sophisticated Monte Carlo simulation engine that processes real-world Formula 1 race data to generate statistically robust team recommendations. The system combines multiple data sources, advanced statistical modelling, and risk assessment algorithms to provide users with optimal fantasy team selections across different budget constraints.
At its core, the system runs 10,000 Monte Carlo simulations per race weekend, incorporating track-specific characteristics, driver performance parameters, and team dynamics to model realistic race outcomes. The engine processes historical race data from the 2025 F1 season, continuously updating driver performance metrics and team competitiveness indicators through data-driven parameter calculation.
Driver Performance Modelling
Driver performance is modelled using data-driven parameters calculated from aggregated historical race data. Each driver's performance is characterised by statistical distributions derived from qualifying and race lap times.
μq,i = E[Qualifying Timesi]   ← Average qualifying lap time for driver i
σq,i = √Var[Qualifying Timesi]   ← Variability in qualifying performance
μr,i = E[Race Lap Timesi]   ← Average race lap time for driver i
σr,i = √Var[Race Lap Timesi]   ← Variability in race performance
pDNF,i = DNF Counti / Total Racesi   ← Probability of not finishing per race
μtyre,i = E[Tyre Degradationi]   ← Average tyre wear per lap (seconds)
σtyre,i = √Var[Tyre Degradationi]   ← Variability in tyre degradation
Driver Set: D = {1, 2, ..., 20}   ← All 20 drivers from the 2025 F1 season
Monte Carlo Simulation Engine
The engine executes 10,000 Monte Carlo simulations per race, modelling stochastic race outcomes through lap-by-lap simulation with data-driven volatility factors.
Qualifying: Tq,i ~ N(μq,i, σq,i²)   ← Normal distribution of qualifying times
Grid Position: Pi = 1 + (Tq,i - minj Tq,j) / 0.1   ← Position based on time gaps (0.1s = 1 position)
Race Lap Time: Tr,i(l) ~ N(μr,i, (0.3σr,i)²)   ← Reduced variance for more realistic racing
Tyre Degradation: Δtyre(l) ~ N(μtyre,i · l/10, σtyre,i²)   ← Progressive tyre wear over race distance
Fuel Effect: Δfuel(l) = -0.5 · l/Ltotal   ← Cars get faster as fuel burns off
Traffic Penalty: Δtraffic(l) = (Pi(l-1) - 1) · θovertaking · 0.1   ← Slower cars in traffic lose more time
DNF Probability: pDNF(l) = pDNF,i / Ltotal   ← Per-lap probability of retirement
Total Lap Time: Ttotal,i(l) = Tr,i(l) + Δtyre(l) + Δfuel(l) + Δtraffic(l) + Δweather(l) + ΔSC(l)   ← Sum of all lap time effects
Data-Driven Volatility Calculation
Volatility factors are calculated from historical performance consistency and track characteristics to model realistic position changes.
CVr,i = σr,i / μr,i,    CVq,i = σq,i / μq,i
CVcombined,i = 0.7CVr,i + 0.3CVq,i
vdriver,i = max(0.1, min(0.35, 50.0 · CVcombined,i))
vbase = 0.5 + 0.5θovertaking
mSC = 1.0 + 0.5pSC
mweather = 1.0 + 0.3pweather
vtrack = vbase · mSC · mweather
\begin{align} \Delta P_i^{(l)} &= 1.2 \cdot \text{pace\_advantage}_i + \epsilon_i^{(l)} \\ \epsilon_i^{(l)} &\sim \mathcal{N}(0, v_{\text{driver},i} \cdot 0.4 + v_{\text{track}} \cdot 0.2) \end{align}

Multi-Objective Team Optimisation
Team selection employs multi-objective optimisation balancing expected value maximisation with risk-adjusted portfolio theory.
Expected Value: EVtotal = Σi∈S E[Pi] + Σj∈T E[Cj] + maxi∈S E[Pi]
Risk-Adjusted Score: RA = EVtotal - λσ²portfolio + γ(EVtotal / (Σi∈S ci + Σj∈T Cj))
Constructor Points: E[Cj] = Σi∈Teamj E[Pi] + Bqual + Bpit
Bqual = {10 if both Q3, 3 if both Q2, 1 if one Q2, -1 if neither Q2}
Bpit = {15 if world record, 5 if fastest, 0 otherwise}
Constraints: |S| = 5, |T| = 2, Σi∈S ci + Σj∈T Cj ≤ 115.1
Team Limit: |{i ∈ S : team(i) = t}| ≤ 2 ∀t
Parameters: λ = 0.15, γ = 0.7
Engine Output Analysis
The Monte Carlo engine generates comprehensive statistical outputs from 10,000 simulations enabling robust decision-making and performance analysis.
Driver Statistics: Si = {E[Pi], σPi, P(wini), P(podiumi), E[positioni]}
Position Distribution: fi(p) = (1/Nsim) Σs=1Nsim 1[Pi(s) = p]
Confidence Intervals: CI95% = E[Pi] ± 1.96(σPi / √Nsim)
Team Value: Vteam = Σi∈S E[Pi] + Σj∈T E[Cj] + maxi∈S E[Pi]
Value Efficiency: η = Vteam / (Σi∈S ci + Σj∈T Cj)
Risk Score: R = √Var[Σi∈S Pi + Σj∈T Cj]
